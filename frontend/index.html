How this DApp works

  • ทำไมใช้ blockchain: ใครก็ตรวจได้ว่าตั๋วมีจริง เป็นของใคร ใช้แล้วหรือยัง กันตั๋วปลอมและใช้ซ้ำโดยไม่ต้องเชื่อใจระบบกลาง
  • เก็บอะไร on-chain: ticket ID, owner, used, ราคา, จำนวนตั๋ว (ข้อมูลน้อยเพื่อลดค่า gas)
  • ทำไมออกแบบแบบนี้: ตั๋วซื้อได้เมื่อจ่าย ETH ครบ จำกัด 5 ใบ/wallet, มีแค่ organizer ที่ check-in/ถอนเงินได้, check-in ซ้ำไม่ได้, ใช้ event เก็บประวัติ
  • ข้อจำกัด: ข้อมูลเป็น public, ต้องมี wallet+ค่า gas, แชร์ wallet = แชร์ตั๋ว, รองรับ event เดียว
